
# 🧩 Extension scenarios

[Spec](README.md) / Extensions

Kinds of addition StoupyNet must welcome, each with the most it may cost: files touched, edits to the core, lines of code.
Each scenario names a decision likely to change, so the architecture draws a boundary around it ([Parnas, 1972](https://doi.org/10.1145/361598.361623)).
IDs: `EXT`.
