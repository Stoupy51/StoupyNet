
# 🎬 Use cases

[Spec](README.md) / Use cases

The programs StoupyNet must keep short: each use case states what a user achieves, and the most user code it may take.
They become the reference examples of the architecture, then tests run in CI.
IDs: `UC`.

## Format

```markdown
### <a name="uc-01"></a>UC-01 Short title
What the user achieves, from which inputs, with which outputs.
- Budget: N lines of user code, imports excluded.
- Relies on: links to the items it exercises.
- Sources: V. Priority: v1.
```

The use cases and their budgets are settled in the vision interview ([Q-01](open-questions.md#q-01), [Q-02](open-questions.md#q-02)).
